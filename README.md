# Protiva

到饭点推附近**好吃、不超卡、蛋白够**的菜。有网 + 开定位，哪里都能用。  
**性价比只是可选排序。**

## 现在怎么用（推荐）

1. 合并 / 部署到 GitHub Pages 后，用**手机 Safari / Chrome** 打开站点  
2. **添加到主屏幕**（PWA）：  
   - iPhone：分享 →「添加到主屏幕」  
   - Android Chrome：菜单 →「安装应用」/「添加到主屏幕」  
3. 允许定位，设目标，看附近 Top 3  
4. 自己用 1–2 周，再给 5–10 个朋友试  

Pages 地址（部署后）：  
`https://williamswu1987-cmd.github.io/-williamswu1987-cmd.github.io/`

## 产品

- 定位搜附近餐厅；硬条件：不超卡、蛋白够  
- 偏好：好吃 / 蛋白 / 最近 / 性价比  
- Freemium：免费每天 3 次定位；Protiva Pro 付费墙（真 IAP 上架前为模拟）  
- PWA：可安装到主屏幕  

## 本地

```bash
npm run serve
```

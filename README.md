# NearBite

到饭点推附近**好吃、不超卡、蛋白够**的菜。有网 + 开定位，哪里都能用。  
**性价比只是可选排序。**

品牌名 **NearBite**：Near（附近定位）+ Bite（那一口好饭）——按卡路里与蛋白，推你附近值得吃的一盘。

## 现在怎么用（推荐）

**线上地址（已部署，HTTPS）：**  
https://185-222-242-227.sslip.io/protiva/

1. 用**手机 Safari / Chrome** 打开上面链接  
2. **添加到主屏幕**（PWA）：  
   - iPhone：分享 →「添加到主屏幕」  
   - Android Chrome：菜单 →「安装应用」/「添加到主屏幕」  
3. 允许定位，设目标，看附近 Top 3  
4. 自己用 1–2 周，再给 5–10 个朋友试  

可选：在 GitHub 仓库 Settings → Pages 打开 `main` 根目录，也可走 GitHub Pages。

## 产品

- 定位搜附近餐厅；硬条件：不超卡、蛋白够  
- 偏好：好吃 / 蛋白 / 最近 / 性价比  
- Freemium：免费每天 3 次定位；NearBite Pro 付费墙（真 IAP 上架前为模拟）  
- PWA：可安装到主屏幕

# Protiva

黑客松 MVP：到饭点推附近**蛋白性价比最高**的菜。手机网页版，城市先做 **Tivat**（10 店 / 30 菜人工数据）。

## 打开

GitHub Pages 部署后访问仓库站点根路径，或本地：

```bash
python3 -m http.server 8080
```

打开 `http://localhost:8080`。

## 核心流程

1. 设一次目标（体重 / 卡路里 / 蛋白 / 预算 / 忌口）
2. 看附近 Top 3（按蛋白/€，兼顾剩余热量与步行）
3. 打开详情：当地话点餐句 + 步行导航
4. 吃完一点，扣今日剩余额度

演示按钮可将剩余额度设为 **1050 kcal / 120g 蛋白**（对应报名备注里的讲故事脚本）。

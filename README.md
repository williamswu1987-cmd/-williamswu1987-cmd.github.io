# Protiva

到饭点推附近**蛋白性价比最高**的菜。手机网页版：**有网 + 开定位，哪里都能用**。

## 怎么用

1. 允许浏览器定位  
2. 设一次目标（卡路里 / 蛋白 / 预算 / 忌口）  
3. 看附近 Top 3（按蛋白/€，兼顾步行距离）  
4. 打开详情：点餐句 + 步行导航；吃完扣今日额度  

定位失败时可改用内置 **Tivat 演示菜单**。

## 数据说明

- 附近餐厅来自 OpenStreetMap（Overpass，失败时回退 Photon）  
- **真实菜单很少公开**，因此菜品与营养按菜系模板估算，并标明可信度  
- 价格为约合欧元的粗估，会随国家做简单系数调整  

## 本地打开

```bash
python3 -m http.server 8080
```

手机访问同一 Wi‑Fi 下的电脑 IP，或部署到 GitHub Pages / HTTPS 域名（定位在多数浏览器要求安全上下文）。
